# NR/SR画质评估决策

## 当前决策

**模型与原图有差异，不等于存在缺陷。** NR的目标本来就是改变光照、材质和局部细节；不要求非中性输出保持原亮度、纹理或像素恒等。改动像素数、最大差异、暗部亮度倍率和梯度统计都只是诊断数据，不是质量分数，也不单独作为阻塞条件。

用户已明确质疑将NR预期变化当问题，当前按以下标准执行：

- **接入正确性**：帧/输入输出身份、颜色/深度/运动语义、有效区域、UI分离、格式/数值有效性、同步/生命周期、状态恢复。出现错帧、错位、NaN、UI被处理、区域污染等有证据的问题必须修复。
- **模型预期改动**：补光、阴影变化、反射与材质重建、局部纹理调整。允许偏离原图，以可见效果及用户偏好判断，不按像素不一致判失败。
- **待确认画质异常**：不合理亮斑、物体形状/材质被改坏、持续细节丢失、运动闪烁、拖影和跨帧光照不稳定。必须给出具体位置/帧、对照和可见表现；数值异常点仅用于定位，不提前称已确认缺陷。

## 已有结果应如何解释

### NR暗部增亮倍率

当前prewarp链记录11个暗部通道增亮超过10倍、最大约17.1倍，这是**值得查看的局部改动，不是已确认NR错误**。分母很接近黑色时，较小绝对变化也会产生很大倍率；补间接光同样会主动提高暗部。

在未观察到不合理亮斑、材质破坏或跨帧闪烁之前：

- 不仅因倍率大而加入gain clamp、削弱NR或增加高光/暗部补偿。
- 不因这一统计阻塞连续帧、插入位置或回接推进。
- 保留原始未钳制输出与数据，比较原图/NR/NR+SR的实际画面。

既有文档中的“暗部风险”“未验收”应按此理解为尚未完成视觉/动态检查，不能读成已有缺陷结论。中性旁路仍应保持恒等，因为中性测试验证的是接入/编解码；它不把同样要求强加给实际NR输出。

### SR细小高光衰减与FXAA差异

SR以重建/抗锯齿为目标，稀疏、不稳定亮点变平滑可能符合预期；持续丢失真实细节才可能是缺陷。已有合成控制只证明空间结构相关响应，不能根据峰值降低直接归因曝光错误或判坏。

FXAA保留时相邻亮度变化较小，只说明额外空间平滑，不等于质量变差。旁路FXAA是下一阶段的实验候选，仍保留原FXAA对照；最终选择要看运动时锯齿、闪烁和用户观感。

## 接下来怎样判断

1. 继续保持可程序验证的接入检查，不放松源身份、区域、UI、数值和生命周期要求。
2. 对同一可信序列比较原图、仅NR、NR+SR；明确FXAA状态、分辨率、P1暂用和Reset/历史条件，避免把其他变量混入模型差异。
3. 优先观察飞机/导弹轮廓、遮挡、海面细高光、云/透明效果，以及明暗变化时的稳定性。用局部静态图定位，连续帧判断是否闪烁/拖影或有不合理变化。
4. 只有出现具体可见异常，才追查模型、引导、曝光、代理恢复或回接原因。用户对效果的偏好也是最终画质判断依据。

当前单Reset离线链已通过若干明确的接入检查，**没有据此证明画质更好，也没有据暗部倍率宣布NR有错**。下一步仍是准备真实相邻帧/jitter/history/reset的窄方案；P1暂用、预曝光调查延后，不重开无边界静态追查。
